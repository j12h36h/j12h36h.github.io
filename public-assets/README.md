# Public Assets

Static public asset payloads used by the E.R.A.S. asset marketplace live here.

`catalog.json` is the marketplace index. Owning an asset does not duplicate the file into Firestore; Firestore stores the signed-in profile's inventory record and per-user configuration such as tint.

GOOGLE / FIREBASE
=================
The Firebase Web App API key in the browser config is public client configuration by design.
A GitHub Pages site cannot hide a value that the browser must receive. Do not obfuscate the
key to bypass secret scanning. Restrict the key in Google Cloud to the required Firebase APIs
and intended browser/referrer scope. Rotate it first if it was previously insufficiently restricted.

For live Google login:
- Enable Google in Firebase Authentication.
- Add j12h36h.github.io to Firebase Authorized domains.
- Create Cloud Firestore.
- Deploy logicalcommunicationservice/firestore.rules.

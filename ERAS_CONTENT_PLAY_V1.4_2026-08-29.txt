E.R.A.S. Content + Play MVP v1.4 — 2026-08-29

CONTENT / ASSET MARKETPLACE
- Replaced /content/ creator screen with the first public asset marketplace.
- Added /public-assets/catalog.json as the static marketplace catalog.
- Added a free tintable Monochrome Slime texture and thumbnail under /public-assets/textures/.
- Added live tint preview with quick color swatches.
- Added Firestore-backed per-profile asset inventory.
- Acquiring the asset is idempotent; owning it again updates its selected tint.
- Inventory tint can be changed later and is saved to Firestore.
- Uses the same LCS/Firebase profile session as /account/.

PLAY HUB
- Replaced the five stationary navigation nodes on /game/ with three orbiting nodes:
  HOST -> /game/host/
  JOIN -> /game/join/
  GLOBAL -> /game/global/
- Node names/details appear on hover/focus.
- Each node pauses its orbit while hovered/focused.

HOST
- Added Firestore-backed game creator / lobby creation.
- Supports lobby name, visibility (public/friends/code), player cap, map template, style, and description.
- Generates a six-character join code.
- Host gets a lobby dashboard, Enter Game, and Close Lobby controls.
- Lobby heartbeat marks abandoned lobbies stale for discovery clients.

JOIN
- Added three discovery modes: Friends, Public Lobbies, Direct Code.
- Friends are loaded from accepted LCS privateFriendships.
- Public lobby discovery uses open Firestore lobby documents.
- Direct code joins by six-character lobby code.
- Joining creates/refreshes the player's lobby member record then enters the lobby world.

GLOBAL
- Added first 2D top-down shared map.
- Players are represented by their actual LCS/account avatar JSON icon.
- Keyboard: WASD / arrow keys.
- Mobile: touch D-pad.
- Firestore stores low-frequency x/y + velocity presence snapshots; clients interpolate locally between writes.
- Global can run as the public shared world or as an isolated hosted-lobby world via ?lobby=<id>.
- Stale presence records are hidden client-side; clients also attempt to remove their own presence on page exit.

FIRESTORE
- Added assetInventory/{profileId}/items/{assetId} rules.
- Added gameLobbies/{lobbyId} + members subcollection rules.
- Added gamePresence/{presenceId} rules.
- Root Founder/LCS/project status behavior from v0.9.7 is preserved.

NOTE
Firestore has a free tier but is not unlimited/no-cost at arbitrary multiplayer scale. This MVP deliberately keeps movement writes low-frequency and interpolates locally. If E.R.A.S. later needs high-frequency combat/physics networking at scale, Firestore should remain the persistence/lobby layer while a lower-cost realtime transport handles frame-state.

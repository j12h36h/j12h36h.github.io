& Impulses

DAI 1.9.5 builds on the game-maker expansion and closes a major distribution gap: DAI-managed and DAI companion resource packs can now stay automatically enabled across installs, renamed/versioned updates and restarts. Standalone addons, moving living portals, generated dimensions/world types and the integrated Creator gameplay tester remain first-class systems.

1.9.5 / RESOURCE COMPANIONSResource packs stay enabled

Managed packs and normal DAI companion packs can be selected automatically, survive renamed/versioned updates, and avoid the manual Resource Packs screen loop.

1.9.5 / STANDALONE ADDONSAddons without a MAIN

Global DAI addons can now layer into ordinary worlds without requiring a selected main experience.

1.9.5 / LIVING PORTALSEntities can be portals

Registry-backed living DAI entities can expose configurable portal destinations, trigger volumes, cooldowns and transfer behavior.

1.9.5 / MOVEMENTMoving portals from JSON

Use stationary, drift, wander, follow, flee, orbit or relocation movement profiles without project-specific Java.

1.9.5 / DIMENSIONSReal custom dimensions

High-level DAI dimension definitions compile into Minecraft startup registry data for real custom dimensions.

1.9.5 / WORLD TYPESVoid, water & flat worlds

Experience worldgen can choose normal, amplified, large-biome, single-biome, debug, void, water, fixed-biome noise or custom flat layers.

1.9.5 / CREATOR TESTERPlay before export

The Creator can build a browser test scene from the current project for logic, reaction, item, entity, portal and world-flow testing.

Resource Packs That Survive Updates

DAI 1.9.5 treats presentation companions as part of the game delivery workflow instead of making players re-enable a renamed ZIP after every update.

Official / Managed

Installed through DAI with a stable dai_managed:* identity and kept in Minecraft's saved + live enabled selection.

+

Normal Companion ZIP

Place it in /resourcepacks. DAI can match its asset namespace to a global DAI datapack or use explicit dai.auto_enable + dai.companion_id metadata.

Version-safe: when a companion filename changes, DAI removes the previously owned file/OldName.zip selection and selects the newest matching companion without touching unrelated user resource packs.

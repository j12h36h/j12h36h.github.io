Decisions
& Impulses

DAI 1.9.2 pushes the framework further toward full game and modpack creation: build native JSON entities with custom AI and hitboxes, layer unlimited addon datapacks around one main experience, and give players meaningful control over automation, performance and presentation without giving up creator-authored game rules.

1.9.2 / NATIVE ENTITIESNative JSON mobs

Create real DAI entity types without inheriting Zombie, Skeleton, Spider, or other vanilla species behavior.

1.9.2 / JSON AIAI + hitboxes from data

Define physical width/height, attributes, targeting, pursuit, melee, fleeing and wandering through JSON behavior profiles.

1.9.2 / PACK STACK1 main + unlimited addons

Launch one game-owning experience while layering any number of explicitly declared or legacy-detected DAI addons.

1.9.2 / CREATOR CONTROLPlayer + game-maker controls

Players set their automation/performance ceiling; the active experience may restrict it further but can never force-enable disabled control.

1.9.2 / CONFIGConfig-aware gameplay

Datapacks can query supported player settings with the new config_value condition and adapt optional gameplay or presentation.

1.9.2 / COMPATIBILITYOld packs still work

Legacy carrier entities, undeclared datapack roles and older config files remain supported while new systems stay opt-in.

One Game, As Many Addons As You Want

DAI 1.9.2 keeps the global /datapacks library but now understands pack roles. A launched save gets one selected main experience plus every enabled DAI addon, then Minecraft reloads the combined stack once.

DAI 2.1 // CURRENT SIGNAL

The engine underneath the worlds.

2.1 INPUT CONTROLDatapacks can read physical and custom keybind state directly

DAI 2.1 adds universal left-click input, a per-tick input reaction, and JSON conditions for registered keybind held, press, release and existence state—including mappings registered by other NeoForge mods.

DIRECTIONAL COMBATFirst-person weapons can move like the attack they represent

DAI provides a client render/input path used by Musashi Story for eight screen-space slash directions, a neutral forward thrust and a half-draw guard instead of Minecraft's default vertical hand bob.

CAMERA-DRIVEN INPUTLook movement can become combat intent

The Musashi reference implementation captures the draw-origin camera angle, resolves directional motion after a five-degree threshold and synchronizes the physical hand/weapon pose with the matching screen effect.

SELECTIVE VANILLA OVERRIDECustom combat does not need to replace Minecraft globally

Vanilla attack/use presentation is suppressed only for supported experience weapons, preserving normal controls and compatibility everywhere else.

MOD-JAR + GLOBAL DATADAI experiences can ship as ZIPs or inside mods

DAI keeps the 1.9.9 distribution foundation: early mod-JAR DAI discovery, stable global pack identities and automatic replacement of stale save-local versions.

NATIVE MINECRAFT BRIDGEContent stays close to Minecraft

Registry-backed content, Data Components, native entities, world data, dimensions and Mojang registries remain available through JSON rather than requiring a parallel engine for every system.

FULL EXPERIENCE BRANDINGGames can own the presentation

MAIN experiences can control title presentation, application branding, startup/loading assets, companion resources and authored game flow while ADDON packs remain stackable.

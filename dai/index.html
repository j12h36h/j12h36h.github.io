DAI 1.9.7 // CURRENT SIGNAL

The engine underneath the worlds.

OPEN MOJANG BRIDGENative Minecraft data without duplicate engines

DAI can compile friendly JSON into Mojang registries and server-data paths, with dai_registry and dai_data as future-proof escape hatches.

DATA COMPONENTSNative item components from JSON

Registry-backed DAI items can define Minecraft Data Components directly through the registered component codecs discovered at runtime.

NATURAL GENERATIONWorlds populate themselves

Reusable structures, features and custom DAI entities can generate or spawn naturally with deterministic placement, biome/dimension filters and authored limits.

FULL EXPERIENCE BRANDINGGames can own the presentation

MAIN experiences can brand the application window, FML startup, resource loading, world generation, terrain entry and title presentation through their companion resource pack.

NATIVE WORLDSBiomes, dimensions and environment attributes

DAI compiles custom biomes, dimension types, timelines and dimensions into Minecraft-native data while exposing sky, fog, clouds, lighting and celestial presentation.

RUNTIME CAPABILITIESAsk the engine what exists

DAI discovers Minecraft registry keys, built-in Data Components and direct bridge folders and writes a machine-readable capability catalog for creators and tools.

DAI 3.9 · MODULAR DATA-DRIVEN ENGINE

DAI Engine 3.9 Update

3.9 generalizes presentation, story, input and Creator systems so packs define experiences while Java provides reusable runtime primitives.

What changed

Screen Overrides

JSON can replace or skin matching vanilla/modded screens while preserving native behavior when needed.

Scene Environments

Reusable animated backgrounds/viewports with camera keyframes, interpolation, drift, shake and pack resources.

Story Archives

Generic session/event capture, significance scoring, compilation, narration templates and pack-styled viewers. ComicLife is now a profile, not an engine special case.

Input Profiles

Contextual bindings move into pack data instead of permanent project-specific core keybinds.

Creator Schemas

The in-game and browser Creators can be extended using JSON schemas and presets rather than hardcoded module menus.

Module Gating

38 optional runtime modules can be disabled so unused systems avoid unnecessary registration/ticking.

3.9 principle

Engine = capabilities. Datapack = behavior. Resource pack = presentation/assets. Project-specific titles, scene paths, story rules, presets and layouts should live in packs instead of Java.

Creator

The in-game Creator moved to a lighter visual workspace with progressive disclosure. The web Creator now includes a matching 3.9 Visual Studio surface generated from the same schema concepts.

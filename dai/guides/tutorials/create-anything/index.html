Use this order for a first game

  1. Project shellNamespace, pack identity and one safe load path.
  2. StateDefine player/world state before creating large behavior graphs.
  3. One interactionInput → action → server result → feedback.
  4. One challenge and rewardEntity/puzzle/objective plus meaningful progression.
  5. RecoveryDeath, rejoin, invalid input and migration.
  6. PresentationModels, HUD, audio and cinematics after mechanics work.
  7. ReleaseValidate, multiplayer-test and package.

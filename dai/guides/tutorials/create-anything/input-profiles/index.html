DAI 3.9 · input_profiles

Input Profiles

Define contextual controls and bindings in the pack instead of requiring permanent core keybindings.

Folder

data/<namespace>/input_profiles/<id>.json

Starter

{
  "enabled": true,
  "priority": 0,
  "context": "gameplay",
  "bindings": []
}

Input profiles can be scoped to the experience that needs them. Project-only controls should be supplied by that project rather than registered as global DAI defaults.

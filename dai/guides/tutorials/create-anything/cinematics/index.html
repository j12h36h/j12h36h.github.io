DAI 3.9 · STEP-BY-STEP · dai_cinematics

ERAS Cinematics

Import or author retained 2D/3D ERAS/Simple Animation Designer projects and control playback from DAI actions.

Build from scratchTest in Minecraft3.8 source-aligned

1. Export or author an ERAS project

DAI preserves the Simple Animation Designer/ERAS project JSON rather than forcing it into the entity-animation schema. A project may be supplied by datapack at data/<namespace>/dai_cinematics/ or by resource pack at assets/<namespace>/dai/cinematics/. The parser requires mode to be 2D or 3D and duration to be greater than zero.

data/my_game/dai_cinematics/intro.json
{
  "version": 1,
  "title": "Intro",
  "mode": "2D",
  "duration": 4.0,
  "loop": false,
  "canvas": {"width":960,"height":540,"background":"#02090b"},
  "assets": {},
  "objects": [],
  "sounds": [],
  "clips": {},
  "timing": {},
  "post": {},
  "lighting": {},
  "camera": {}
}

2. Know the retained project surfaces

camerapostlightingassetsobjectssoundsclipstiming

Validation limits: the current parser allows at most 2000 objects and 256 sound clips per project; canvas dimensions are clamped to 64–4096.

3. Control playback through actions

cinematic_play
cinematic_stop
cinematic_pause
cinematic_resume
wait_for_cinematic

4. Keep entity animation separate

Use dai_animations for entity/bone animation. Use dai_cinematics for retained 2D/3D ERAS projects with camera/post/object/timing concepts.

DAI 3.9 · scene_environments

Animated Scene Environments

Use a data-defined scene anywhere DAI accepts a scene background or scene-view.

Folder

data/<namespace>/scene_environments/<id>.json

Starter

{
  "enabled": true,
  "background": {"type":"gradient","top":"#17101f","bottom":"#05070d"},
  "camera": {
    "duration_ticks": 1200,
    "loop": true,
    "fov": 60,
    "interpolation": "smooth",
    "motion": {"drift":0.02,"shake":0.0},
    "keyframes": [
      {"tick":0,"position":[0,1,10],"look_at":[0,0,0]},
      {"tick":1200,"position":[2,1,10],"look_at":[0,0,0]}
    ]
  },
  "elements": []
}

Textures/models/audio referenced by the scene belong in the resource pack. The engine renderer is generic; the scene definition decides what is shown.

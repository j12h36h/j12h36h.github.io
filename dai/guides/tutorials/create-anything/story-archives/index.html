DAI 3.9 · story_profiles

Story Archives & Comic/Viewers

Capture meaningful sessions and events, then compile them into pack-defined journals, books, comics or histories.

Folder

data/<namespace>/story_profiles/<id>.json

Starter

{
  "enabled": true,
  "poll_interval_ticks": 5,
  "session": {"start":{},"end":{}},
  "events": [],
  "compiler": {"max_events":18,"panels_per_page":2},
  "viewer": {"layout":"book"}
}

Event rules, significance, titles, narration templates, panel/page structure and scene choice are profile data. This is the framework that allows a ComicLife-style addon without hardcoding ComicLife rules into DAI.

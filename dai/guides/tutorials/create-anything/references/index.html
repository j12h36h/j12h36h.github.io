References

Remember an entity, block or position once and reuse that exact context in later actions, conditions and sequences.

Build from scratchTest in Minecraft3.8 source-aligned

What a DAI reference is

A reference is reusable captured context. 3.8 supports three reference types: ENTITY, BLOCK and POSITION.

1. Capture context

reference_remember_target_entity
reference_remember_target_block
reference_remember_reaction_entity
reference_remember_player_position

2. Select or clear it later

reference_select
reference_clear

Use this when a multi-step sequence should keep acting on the same entity/block/position instead of rescanning every step.

3. Test the captured reference

reference_exists
reference_type
reference_age
reference_distance
reference_entity_alive

Typical pattern

Multi-step target flow
1. scan / recognize a target
2. reference_remember_target_entity
3. perform another action or delay
4. reference_exists + reference_entity_alive
5. reference_select
6. continue against the same target

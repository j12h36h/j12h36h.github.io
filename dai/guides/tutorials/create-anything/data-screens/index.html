DAI_SCREENS

Data Screens

Build a complete client UI from datapack JSON and return cleanly to gameplay.

DAI 3.3JSON-firstTest in Minecraft

Build path

  1. Create the screenAdd dai_screens/status.json.
  2. Add widgetsStart with label/button, then state-driven progress/input controls.
  3. Open itUse open_data_screen with the screen ID in action.
  4. Close cleanlyUse close_screen or explicit cursor recapture.
  5. Test EscapeVerify close_on_escape and pause_game.

Starter JSON

{
  "title":"Status",
  "width":320,
  "height":220,
  "close_on_escape":true,
  "pause_game":false,
  "widgets":[{"type":"button","id":"resume","x":16,"y":176,"width":120,"height":20,"label":"RESUME","action":"my_pack:resume"}]
}

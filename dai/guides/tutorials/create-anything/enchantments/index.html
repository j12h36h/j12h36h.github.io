DAI 3.9 · STEP-BY-STEP · dai_enchantments

Enchantments

Create DAI enchantment content or author a native Mojang enchantment through the direct bridge, depending on which runtime model you need.

Build from scratchTest in Minecraft3.8 source-aligned

Choose the correct enchantment path

PathUse when
dai_enchantmentsYou want a DAI content identity that participates in the DAI content/runtime model.
dai_enchantments_nativeYou want Mojang's native enchantment registry schema compiled directly by the bridge.

DAI content definition

data/my_game/dai_enchantments/steady_edge.json
{
  "display_name": "Steady Edge",
  "description": "A DAI-defined enchantment content entry.",
  "carrier": "minecraft:iron_sword",
  "tags": ["combat"]
}

The exact DAI content model shares the same content definition foundation as items, weapons, effects and other registered content.

Native Mojang definition

Place Mojang-schema enchantment JSON under data/<namespace>/dai_enchantments_native/. DAI compiles it to the native enchantment registry output rather than inventing a parallel schema.

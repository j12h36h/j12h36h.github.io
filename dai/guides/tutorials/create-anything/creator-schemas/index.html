DAI 3.9 · creator_schemas

Creator Schemas & Presets

Extend the Creator itself through datapack JSON.

Folders

data/<namespace>/creator_schemas/<id>.json
data/<namespace>/creator_presets/<id>.json

A schema declares the display name, output folder, category, progressive fields, template, preview adapter and optional layout preferences. Presets apply reusable patches to a schema.

Minimal schema

{
  "display_name": "My Module",
  "folder": "my_modules",
  "rail": "experience",
  "category": "SYSTEMS",
  "fields": [
    {"path":"enabled","label":"Enabled","type":"boolean","default":"true","level":0}
  ],
  "template": {"enabled":true},
  "preview": {"type":"json"}
}

The 3.9 engine ships 45 built-in schemas and starter presets, but the catalog is not a closed Java enum.

DAI 4.1 · screen_overrides

Screen Overrides & Custom Screens

Replace or skin compatible Minecraft, modded and DAI screens through data.

Folder

data/<namespace>/screen_overrides/<id>.json

DAI 4.1 starter

{
  "enabled": true,
  "priority": 0,
  "target": {
    "class": "net.minecraft.client.gui.screens.TitleScreen",
    "simple_class": "",
    "title": "",
    "exclude_class": ""
  },
  "mode": "replace",
  "screen": "my_pack:title",
  "background_scene": "my_pack:title_scene",
  "foreground_scene": ""
}

mode accepts replace, skin, overlay, or hide. Hide is a real runtime mode in 4.1, not just a Creator/schema option.

JSON owns the presentation: Java screens are fallback implementations. A matching datapack override can replace, layer over, restyle, or suppress the screen without editing DAI Engine code.

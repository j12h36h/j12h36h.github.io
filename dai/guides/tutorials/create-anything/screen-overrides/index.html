DAI 3.9 · screen_overrides

Screen Overrides & Custom Screens

Replace or skin compatible Minecraft, modded and DAI screens through data.

Folder

data/<namespace>/screen_overrides/<id>.json

Starter

{
  "enabled": true,
  "priority": 0,
  "target": {"class":"net.minecraft.client.gui.screens.TitleScreen"},
  "mode": "replace",
  "screen": "my_pack:title",
  "background_scene": "my_pack:title_scene"
}

Use replace for complete substitution. Use a native-preserving skin/overlay approach for screens whose container/network behavior must remain intact.

Fallback safety: keep definitions valid and retain a normal-screen fallback so a broken custom screen cannot trap the player.

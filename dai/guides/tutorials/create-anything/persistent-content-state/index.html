Persistent Block Data & Item Components

Build a JSON-owned machine/container and mutate item Data Components without a dedicated Java class per mechanic.

DAI 3.3JSON-firstTest in Minecraft

Build path

  1. Enable block stateSet block_entity/inventory/sync/tick settings.
  2. Write typed stateUse block_entity set/add/toggle/clear actions.
  3. Read itUse block_entity state and slot conditions.
  4. Mutate itemsUse item_component set/remove/copy.
  5. Keep transactions atomicPerform costs + mutation in one authoritative path.

Starter JSON

{
  "block": {
    "block_entity": true,
    "inventory_slots": 9,
    "block_entity_sync": true,
    "block_entity_tick_interval": 20
  }
}

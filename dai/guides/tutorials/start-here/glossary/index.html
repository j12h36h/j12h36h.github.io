Beginner Glossary

Plain-language definitions for the Minecraft, datapack, resource-pack and DAI terminology used throughout the creator documentation.

No coding experience requiredCopyable examplesDAI 3.8

Keep this page open while using the advanced guides.

The reference docs intentionally use precise terminology. This glossary translates the most common terms into beginner language.

TermPlain-language meaning
ActionA DAI operation/primitive that does something.
ADDONA reusable DAI pack that adds features without owning the whole game/save.
ArrayA JSON list written with [ ].
AssetsClient presentation files such as textures, models and sounds.
AuthoritativeThe side whose decision is trusted for gameplay state; usually the server for rewards/world/inventory.
BooleanJSON true or false.
ClientThe Minecraft game process rendering/inputting for a player.
Companion resource packA resource pack associated with a DAI datapack/experience.
ConditionA check that decides whether something is currently true/allowed.
CreatorDAI's guided browser authoring environment.
Data ComponentsModern Minecraft item data/state components.
DatapackMinecraft data/logic package rooted by pack.mcmeta + data/.
DefinitionA JSON resource that describes a DAI/Minecraft object or behavior.
EntityA dynamic world object such as a player, mob or projectile.
ExperienceA DAI game-owning lifecycle definition; commonly part of a MAIN pack.
ExtensionThe ending of a filename, e.g. .json or .mcfunction.
FunctionA .mcfunction file containing Minecraft commands.
Game directoryThe Minecraft instance folder containing mods/, resourcepacks/, saves, etc.
IDA stable machine-readable name used to reference content.
JSONStructured text format DAI uses for definitions.
Load functionA function registered to run when datapack data loads/reloads.
MAINThe single DAI pack that owns a complete experience/save lifecycle in a stack.
MigrationLogic that upgrades old saved state/content to a newer release safely.
NamespaceThe owner prefix in an ID such as my_game in my_game:hello.
Namespaced IDAn address in the form namespace:path.
NeoForgeMinecraft mod loader/API used by the DAI runtime.
ObjectA JSON group of named fields written with { }.
ObjectiveA goal/state flow unit used to structure gameplay progress.
Pack metadatapack.mcmeta; identifies Minecraft compatibility and optional DAI metadata.
PathFolder/file location or the part of a resource ID after the namespace.
ReactionEvent-driven logic that responds to something happening.
RegistryA system mapping stable IDs to known content types.
Resource packMinecraft client presentation package rooted by pack.mcmeta + assets/.
Resource locationAnother name for a namespaced resource ID.
SelectorMinecraft target syntax such as @s, @a or @e.
SequenceOrdered actions/steps.
ServerAuthoritative game logic/world process; integrated server exists even in single-player.
Stable identityAn ID kept unchanged across releases so updates refer to the same logical project/content.
StateInformation describing the current game situation/progression.
TagA Minecraft data resource that groups/points to other resources, e.g. load/tick functions.
TickOne game update step; normally 20 per second under healthy performance.
Universal FilesCreator surface for arbitrary JSON, functions, text, binary and nested pack paths.
ValidationAutomated checks for syntax, paths, references and known schema mistakes.
World-local datapackA datapack inside one save's datapacks/ directory.
ZIP rootThe first level inside a ZIP; pack metadata must be at the expected root.

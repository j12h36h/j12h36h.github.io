DAI 3.9 · LEVEL 0

Start From Zero

Build DAI projects from scratch with no coding, datapack, JSON or packaging knowledge assumed.

No coding experience requiredCopyable examplesDAI 3.9

This course starts before coding.

Use this path if any of these are unfamiliar: file extensions, ZIP roots, pack.mcmeta, namespaces, JSON, .mcfunction, load/tick tags, datapacks, resource packs, or where Minecraft looks for them.

The rest of the DAI documentation can stay technical because this foundation teaches the vocabulary and mechanics once. You do not need Java, a programming background, or prior datapack experience.

What you will be able to do

  • Create folders and real .json/.mcfunction files instead of accidental .txt files.
  • Explain the difference between a datapack, resource pack, DAI MAIN experience and DAI ADDON.
  • Read a namespaced ID such as my_game:hello and know exactly which folder/file it refers to.
  • Read and safely edit JSON without guessing where commas or braces belong.
  • Create and call Minecraft functions, including load/tick entry points.
  • Build a tiny working DAI addon by hand or in Creator.
  • Diagnose a broken reload instead of rebuilding the project blindly.
  • Package a release ZIP with the correct root structure.

Creator or manual files?

Visual Creator

Use Creator when a dedicated editor exists. It reduces syntax mistakes and writes normal pack files for you.

Manual / Universal Files

Use normal files when learning, copying a documented example, or authoring a Minecraft/DAI surface the guided editor does not expose yet.

These are two ways to author the same project, not two incompatible project types.

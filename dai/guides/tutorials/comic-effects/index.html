Build Comic-Style Combat Effects

Turn ordinary gameplay events into punchy visual feedback using reaction phases, overlays, sprites and a companion resource pack.

Inspired by [DAI] Comic Effects30–45 min5 milestones
Build the idea, not a clone. This workshop intentionally recreates a smaller learning version of the public project. It teaches the same categories of DAI systems without pretending to reproduce every private/internal project file.

What You Learn

reaction phasessprite overlaysresource texturesconditional FXsoundcompanion pack

Starter Project Shape

Create only the folders you need for each milestone. The exact final tree can grow as you add your own systems.

Suggested learning layout
data/comic_lab/
├─ dai_reaction_events/
└─ dai_objectives/
assets/comic_lab/
└─ textures/gui/comic/

Build It in Milestones

  1. Pick one readable eventStart with one event such as attack input or a combat reaction instead of building every effect at once.
  2. Create one comic spriteAdd a transparent PNG to the companion resource pack and keep the first effect deliberately simple.
  3. Show the spriteUse overlay actions to place the effect on screen at the chosen phase.
  4. Add timing and cleanupRemove or replace the effect after a short duration so repeated reactions stay readable.
  5. Layer presentationAdd sound, shake-like presentation, or alternate sprites only after the base event is reliable.

Make It Yours

  • Create several randomized onomatopoeia sprites.
  • Use different art for pre/during/post reaction phases.
  • Add a creator setting to disable the most intense effects.

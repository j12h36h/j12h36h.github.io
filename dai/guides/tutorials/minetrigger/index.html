Build a Class-Based Combat Game

Build a small combat arena with loadouts, custom weapons, projectiles, UI and authoritative combat rules.

Inspired by [DAI] MineTrigger2–4 hr6 milestones
Build the idea, not a clone. This workshop intentionally recreates a smaller learning version of the public project. It teaches the same categories of DAI systems without pretending to reproduce every private/internal project file.

Build It in Milestones

  1. Build one class firstCreate a single loadout with one primary weapon and one utility ability before adding class selection.
  2. Add authoritative combatKeep damage, resource costs and entity mutation on the server-authoritative path.
  3. Add a target dummyUse a custom/native entity as a repeatable test target for projectiles and melee.
  4. Create the loadout UIExpose class selection and resource state through a simple menu.
  5. Add a second classOnly after the first loop works, prove the architecture can support genuinely different weapons/abilities.
  6. Test failure statesRun out of resources, miss targets, switch items mid-action and reload the world.

Make It Yours

  • Add team rules and objectives.
  • Create force/blast utility weapons.
  • Add multiple independent ability cooldowns and readiness visuals.

Build a Procedural Dungeon Loop

Create a room-based dungeon game with deterministic state, server-built structures, floor progression and a safe home-room loop.

Inspired by [DAI] AutoCraft MineShaft3–6 hr6 milestones
Build the idea, not a clone. This workshop intentionally recreates a smaller learning version of the public project. It teaches the same categories of DAI systems without pretending to reproduce every private/internal project file.

What You Learn

Create only the folders you need for each milestone. The exact final tree can grow as you add your own systems.

Build It in Milestones

  1. Build the home roomCreate a stable safe room and one exit into the dungeon loop.
  2. Generate one room typeUse a server function/structure to place one complete room with reliable doors and clearance.
  3. Track floor stateStore floor number and room-generation state separately from presentation.
  4. Add multiple room templatesRandomize only after every template obeys the same entrance/exit contract.
  5. Create return + reward flowReturn the player safely, switch the intended gamemode and award a floor-specific memento.
  6. Stress-test generationGenerate many floors, reload mid-run and verify no stale room state leaks into the next floor.

Make It Yours

  • Add biome-themed room pools.
  • Move the dungeon into a dedicated generated dimension.
  • Add rare rooms, bosses and floor-specific trophy models.

Build a Branded Survival Experience

Turn a collection of mechanics into one cohesive MAIN experience with owned saves, custom startup presentation, progression and environment rules.

Inspired by [DAI] Hollow Spiral2–4 hr5 milestones
Build the idea, not a clone. This workshop intentionally recreates a smaller learning version of the public project. It teaches the same categories of DAI systems without pretending to reproduce every private/internal project file.

Build It in Milestones

  1. Create the experience shellOwn a save, define first-join/resume behavior and verify the project launches cleanly.
  2. Give it a visual identityAdd title/loading presentation and a companion resource identity.
  3. Create one progression loopBuild a short objective chain with a clear beginning, checkpoint and completion state.
  4. Shape the worldUse worldgen/bootstrap and environment data to make the experience feel intentionally different from vanilla.
  5. Test returning playersReload, update the pack and verify progression does not reset or duplicate onboarding.

Make It Yours

  • Add a custom dimension as a late-game layer.
  • Create chapter-specific title/loading screens.
  • Turn progression milestones into reusable addons for other MAIN experiences.

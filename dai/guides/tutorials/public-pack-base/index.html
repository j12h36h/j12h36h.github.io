DAI CREATOR · PUBLIC BASES

Start From a Public Pack

Clone a public DAI pack into the Creator, inspect every managed definition and preserve unsupported files while you learn or branch into a derivative project.

1. Open the public-base importer

In the Creator toolbar choose Use Public Pack as Base. Official entries come from the same public /api/packs.json registry used by the DAI ecosystem. You can also provide a direct public ZIP URL.

2. Import and inspect

The normal ZIP importer runs after download: managed DAI definitions become editable forms and every other file is preserved as a Universal File. The optional DAI_CREATOR_BASE_SOURCE.txt records the source link/file so you do not lose provenance.

3. Fork responsibly

Rename the namespace/stable pack ID when creating a distinct project, update resource references, and read the source project’s license before redistributing code/assets. A public download is not automatically permission to relicense or republish everything inside it.

Use the Creator: these schemas can be pasted into the type-specific JSON fields in DAI Content / Runtime Definitions. Unknown fields are preserved on import/export.

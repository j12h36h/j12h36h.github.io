QUICK START · ONE FILE

Replace a visible DAI menu with one JSON file.

This is the fastest DAI learning loop: create one resource override, reload, press the grave/backtick key, and immediately see your own interface.

1 JSONNo Java required.
Visible ResultChange text and styling immediately.
Then GrowPoint the button at your own action when ready.

1. Add this path to your datapack

Resource override path
data/decisions_and_impulses/menus/systems/default.json
Why the DAI namespace? This particular exercise intentionally overrides DAI's built-in systems/default resource. New actions and original content should normally use your own namespace.

2. Put this in default.json

Your first visible DAI menu
{
  "priority": 100,
  "buttons": [
    {
      "slot": 0,
      "id": "my_first_dai_button",
      "text": "MY FIRST DAI MENU",
      "action": "decisions_and_impulses:open_dai_creator",
      "style": {
        "background": "#1A0D16",
        "hover": "#3A1729",
        "selected": "#59213C",
        "text": "#FFF2E8",
        "border": "#FF8A2A"
      }
    }
  ]
}

The example deliberately points at an existing DAI action so the one-file experiment is functional immediately. Change the text and colors first. You can replace the action with your own in the next step.

3. Reload and look at it

  1. Enable the datapack.Use a test world so iteration is disposable.
  2. Run /reload.DAI reloadable data is rebuilt with your overriding menu resource.
  3. Open the DAI menu.Press the grave/backtick key unless your active experience owns that input.
  4. Change one thing.Edit the label or one color, reload again, and verify the difference.

What you just learned

Your datapack
   ↓
DAI resource loading
   ↓
menus/systems/default.json
   ↓
DAI menu renderer
   ↓
button action dispatch

You already crossed the important boundary: your datapack changed DAI behavior without changing the engine.

Next: make the button yours

Create an action definition under your own namespace, for example:

data/my_pack/logics/definitions/hello.json
{
  "type": "sequence",
  "sequence": [
    {
      "type": "run_command",
      "action": "say Hello from my DAI pack"
    }
  ]
}

Then change the button to "action": "my_pack:hello". From there, the Action and Module guides let you replace the demo command with actual gameplay.

About the other half of the default menu

DAI also has menus/actions/default.json. The System and Action definitions are separate resources. You can override either one independently, or both when your interface design needs the entire generic DAI menu replaced.

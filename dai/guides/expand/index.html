GUIDE TYPE 03 · SELECTIVE SOURCE LEARNING

Expand from a public DAI datapack.

Study an existing public project without being forced through every system it contains. Choose the source pack, scan its actual file tree, select only the detected modules you care about, and generate a focused recreation path.

1. Choose a public datapack

The Expand Guide reads the current ZIP list directly from the public DAI GitHub repository data folder. CurseForge file IDs are not used. The source pack remains the reference; nothing is imported into your project automatically.

2. Pick only the modules you want to recreate

Detected modules come from the pack's actual ZIP paths. Selecting a module adds it to your personal guide; leaving it unchecked means you can ignore that part of the source project.

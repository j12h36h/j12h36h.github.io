DAI Engine 3.8 Documentation Update

This guide set is aligned to the uploaded 3.8 source tree, not simply relabeled from 3.3.

SOURCE-DERIVED INVENTORY

What the 3.8 source exposes

266registered actions
273registered conditions
34first-class DAI definition kinds
43direct Mojang bridge folders
Typed state and capabilitiesdai_state defines boolean/number/string state across client session, player, entity, dimension, world and server scopes. Actions mutate state/capabilities and conditions read them.
References as reusable contextEntity, block and position references can be remembered, selected, tested and cleared instead of repeatedly reacquiring the same target.
Server-authoritative skillsdai_skills now has explicit runtime handling for cooldowns, resources, level/job/rank requirements, tags, projectiles and cast dispatch.
Sapphire learning agentslearning/agents definitions expose observations, choices, rewards, imitation, dialogue, grounding, knowledge import and inference controls.
ERAS / Simple Animation Designer cinematicsdai_cinematics retains 2D/3D project JSON and exposes play/stop/pause/resume/wait actions.
Open Minecraft capability discoveryThe runtime reflects Minecraft registry keys and Data Components, publishes capabilities.json, supports 43 friendly bridge folders and retains dai_registry/dai_data escape hatches.

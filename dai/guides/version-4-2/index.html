FINAL ARCHIVED RELEASE · MINECRAFT 26.2

DAI Engine 4.2

DAI 4.2 is the project's final planned update for the foreseeable future. It carries forward the 4.1 JSON-first runtime and adds datapack-driven takeover of the Minecraft title launcher.

Launcher takeover

A datapack can route the title stage through a high-priority dai_shell_presentations definition to a custom DAI screen and a vanilla scene. This makes a complete title experience possible while leaving DAI in charge of the launcher handoff.

Pause screen routing

The canonical screen ID and background-scene ID are both pause. For entry animation, coordinates are canvas-centered rather than measured from the top-left corner.

Compatibility

The schema-4 public pack registry, stable pack IDs, and 4.1 Creator workflows remain compatible. DAI 4.2 becomes the canonical website registry at /dai/api/packs-4.2.json; the 4.1 and 4.0 registry files are retained for older clients. This is an archive/update to the website package, not a claim that the website can change the installed Minecraft mod.

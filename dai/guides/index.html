Start From Zero

For creators with no coding, datapack, JSON or packaging knowledge. Learn the file system, project anatomy, JSON, functions, testing and release ZIPs before touching advanced systems.

  • No prior coding assumed
  • Files/folders/ZIPs from the beginning
  • JSON + .mcfunction fundamentals
  • Known-good first DAI project

Module Guide

Build one individual feature without learning everything around it first. Pick the module your idea needs, create it, test it, and return for another only when necessary.

  • Items, blocks, entities and combat
  • HUD, effects, physics and world systems
  • Automation, persistence and more

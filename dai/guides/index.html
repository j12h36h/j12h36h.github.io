Creator Guides

Build anything from one reusable addon to a complete branded Minecraft game. DAI Engine 2.0 adds the Musashi reference directional-combat render/input path while retaining the action/condition runtime, AI, custom content, native Minecraft bridges, world systems, branding and distribution foundations from 1.9.x.

Current in 2.0: directional first-person weapon rendering, camera-driven slash intent, neutral thrust + guard states, mod-JAR MAIN/ADDON data discovery, stable datapack identity/version synchronization, 229 documented actions/behaviors, 257 documented conditions, native Data Components/Mojang bridges, natural entities/worldgen and automatic companion-resource lifecycle.

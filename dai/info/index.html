What is DAI?

Decisions and Impulses is a reusable Minecraft automation runtime. The mod supplies capabilities; datapacks define the gameplay built from those capabilities.

Engine, Not One Fixed Game Mode

DAI provides movement, navigation, camera control, targeting, block and entity perception, mining, placement, inventory interaction, crafting, combat, Creative construction, conditions, menus, objectives, runtime recovery, and more.

What Can Be Built?

Survival

Resource gathering, tools, food, shelter, mining, exploration, combat, progression, and custom strategies.

Creative

Physical player-controlled structure building using Creative inventory, flight, camera control, and placement.

Adventure

Scripted routes, interactions, combat, objectives, landmarks, quests, and custom-map automation.

Modular by Design

Gameplay modes can live in separate datapacks and namespaces, allowing creators to add, replace, or remove gameplay behavior without rewriting the DAI Java runtime.

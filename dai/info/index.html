What is DAI?

Decisions and Impulses is a reusable Minecraft automation runtime. The mod supplies capabilities; datapacks define the gameplay built from those capabilities.

Engine, Not One Fixed Game Mode

DAI provides movement, navigation, camera control, targeting, block and entity perception, mining, placement, inventory interaction, crafting, combat, Creative construction, conditions, menus, objectives, runtime recovery, reactions, custom button styling, screen sprites, animated sprite sheets, and more.

What Can Be Built?

Survival

Resource gathering, tools, food, shelter, mining, exploration, combat, progression, and custom strategies.

Creative

Physical player-controlled structure building using Creative inventory, flight, camera control, and placement.

Adventure

Scripted routes, interactions, combat, objectives, landmarks, quests, and custom-map automation.

Events & Presentation Are Datapack Systems Too

Reactions let JSON subscribe to registered runtime events and run normal DAI sequences in pre, during, or post phases. Presentation actions can draw static resource-pack sprites or animated sprite sheets on screen, tint and layer them, and optionally make them interactive.

Modular by Design

Gameplay modes can live in separate datapacks and namespaces, allowing creators to add, replace, or remove gameplay behavior without rewriting the DAI Java runtime.

Example / Proof of Concept

DAI Fundamentals — Survival

Official DAI Datapack Survival Example Pack Proof of Concept

DAI Fundamentals — Survival is the default example and proof-of-concept gameplay datapack for Decisions and Impulses. It demonstrates how a completely external datapack can use the DAI framework to create its own Survival gameplay, menus, perception, objectives, and autonomous behavior without modifying the core mod.

The pack adds its own [D-F] Survival entry to DAI and demonstrates contextual gameplay menus including Explore, Attack, Hunt, and Harvest. Available actions can react to the world around the player, allowing datapack-defined behavior to appear only when it is relevant.

Its most developed example is connected tree harvesting. The pack demonstrates how smaller DAI objectives can locate logs, remember targets as waypoints, approach and mine them, scan adjacent blocks, continue through connected wood, recover nearby branches, collect dropped items, and clean up temporary runtime state.

  • External Survival gameplay namespace
  • Custom Automation menu contribution
  • Contextual Available menus
  • Explore / Attack / Hunt / Harvest structure
  • Recognition-driven behavior
  • Connected-log tree harvesting example
  • Waypoint and spatial scanning usage
  • Reusable objective composition
  • Third-party recognition examples
  • Proof-of-concept framework demonstration
This pack is intended primarily as an example/default starter pack rather than a complete autonomous Survival AI. Some gameplay entries are demonstrations or expansion points intended to show third-party creators how DAI systems can be combined.

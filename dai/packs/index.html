Official DAI 1.9.1 Ecosystem

Official Packs

This page and the in-game DAI Pack Browser share the same official registry. DAI 1.9.1 combines client presentation, server-authoritative datapack behavior, a global datapack library, expanded interaction reactions, and the new JSON game-customization layer. Official datapacks install into /datapacks, companion resource packs install client-wide, and complete experiences can deploy their datapack into the correct owned save when launched.

In-Game Pack Registry

The mod reads the live catalog from /dai/api/packs.json. Only approved, installable CurseForge files belong in that live JSON. Upcoming entries are staged separately until both component file IDs are public.

The website decides which packs are official. CurseForge remains the download host. Combo packs appear as one browser card while still installing all datapack/resource-pack components. packs.pending.json is staging metadata only and is intentionally not consumed by the in-game browser.

    ↓

Managed resource packs installed by the DAI browser are auto-enabled. Global datapacks are a DAI library and are deployed into the appropriate experience save instead of being force-enabled in every world.

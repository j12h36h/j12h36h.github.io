DAI ENGINE 3.3 ECOSYSTEM

Official Projects

The current DAI ecosystem spans complete MAIN experiences, reusable ADDON datapacks, companion resource packs and ready-to-play modpack distributions. This directory is broader than the in-game installer registry and can list projects from either their public GitHub source or their CurseForge project page.

Current DAI 3.3 Project Line

The website now tracks the expanded public project line: Space Between Blocks 0.1.19, Tower of DLC 0.1.4, Kitty's Dagger 0.4, AutoCraft MineShaft, ClayGrounds, Hollow Spiral, MineTrigger, Musashi Story, TamaCrafti, Echo Time, Damage Indicators, Survival Interface, Comic Effects and DAI Fun.

Installer safety: the in-game api/packs.json remains tied to published CurseForge component file IDs. Documentation may describe newer source releases before those file IDs are public; the site will not invent download IDs.
DAI Engine 3.3: the engine/core project remains at the existing CurseForge slug while the public branding is now DAI Engine. Internal decisions_and_impulses namespaces and installer IDs remain stable for compatibility.

Normal companion ZIPs can auto-enable through matching namespaces or explicit dai.auto_enable / dai.companion_id metadata. Stable IDs allow renamed/versioned updates without disturbing unrelated resource packs.

Learn From a Public Pack

The DAI Creator can use public packs as editable starting bases. The Creator now reads a dedicated GitHub-backed /api/public-bases.json registry instead of constructing browser downloads from CurseForge file IDs; direct public ZIP URLs still work too.

Derivative-work reminder: importing a public ZIP is a technical convenience, not a license grant. Keep source attribution and follow the pack's license before publishing modified code/assets.

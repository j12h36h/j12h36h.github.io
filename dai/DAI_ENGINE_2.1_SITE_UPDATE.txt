- DAI Universe home page visual identity retained.
- Normalized remaining current-facing DAI 2.0 labels across Official Packs, Creator, metadata and guides to DAI 2.1 or version-neutral wording.
- Added DAI 2.1 universal physical left-click reaction coverage.
- Added DAI 2.1 per-tick physical-input reaction coverage.
- Added JSON keybind_held, keybind_pressed, keybind_released and keybind_exists documentation.

- Creator reference catalog updated from 257 to 263 documented conditions.
- Creator reaction reference updated from 5 to 7 built-in reaction events.

Native Exposure Pass II website/Creator refresh

- Documented native block physical properties, states, shapes, redstone and lifecycle callbacks.
- Documented item lifecycle hooks, entity combat/interact/death/riding lifecycle, projectile physics, real vehicle input, standalone portals/interactives, native particles/effects/potions and fluid behavior.
- Added a dedicated Native Runtime Exposure reference page.
- Added new learn-by-building tutorials for native blocks, entity lifecycle, projectiles, vehicles, standalone portals, particles/effects/fluids, and public-pack bases.
- Expanded Quick Recipes with native runtime patterns.
- Creator DAI Content editor now preserves/edits block, projectile, particle, effect and potion specialization JSON instead of dropping those fields on import.
- Creator native registry selector now exposes item/block/entity/effect/potion/particle.
- Added native block/projectile/particle/effect starter templates and updated runtime templates for vehicles, standalone portals, interactives and fluids.
- Added “Use Public Pack as Base” to the Creator. Official public registry components resolve from /api/packs.json; any direct public ZIP URL can also be imported when CORS permits.
- Public-base imports can add DAI_CREATOR_BASE_SOURCE.txt so source provenance is preserved while users learn/fork.
- Public-base UI explicitly reminds creators that public availability is not a license grant.

# LCS v0.7.3 — Transformable Character Avatars

- Adds per-layer `scaleX` and `scaleY` from -4 through 4.
- Adds per-layer `skewX` and `skewY` from -75 through 75 degrees.
- Negative scale values mirror glyphs, while independent X/Y scaling enables wide, narrow, flattened, elongated, and intentionally malformed shapes.
- All transforms are optional and older avatar JSON remains compatible.
- Rendering is still generated by LCS from validated values; raw SVG, HTML, CSS, transform strings, URLs, uploads, and scripts remain forbidden.
- Keeps the v0.7.2 multilingual Unicode glyph support and v0.7.1 96-layer / 32,000-character limits.

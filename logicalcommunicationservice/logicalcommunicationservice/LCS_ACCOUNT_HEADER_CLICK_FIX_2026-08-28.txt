LCS ACCOUNT HEADER CLICK FIX — 2026-08-28

Issue
-----
On narrow/mobile layouts, the CSS rule `.auth-user span { display:none; }` hid both
the signed-in display name AND the initials avatar. Because public Google profile
pictures are intentionally opt-in/off by default, most users therefore saw only
the sign-out button in the header.

Fixes
-----
1. Mobile CSS now hides only the display-name label, never the initials avatar.
2. The header account identity keeps a minimum 36x36 click target.
3. Header account clicks are handled through a persistent delegated listener on
   #authArea, so re-rendering authentication state cannot drop the account click.
4. Added explicit title and aria-label to the account identity button.
5. Added cache-busting query versions to the LCS CSS and app.js references so
   GitHub Pages/browser caches do not keep the broken mobile styles.

Expected behavior
-----------------
Signed in, desktop: avatar + public display name + sign-out icon. Clicking avatar
or display name opens Account.

Signed in, narrow/mobile: avatar + sign-out icon. Clicking the avatar opens
Account.

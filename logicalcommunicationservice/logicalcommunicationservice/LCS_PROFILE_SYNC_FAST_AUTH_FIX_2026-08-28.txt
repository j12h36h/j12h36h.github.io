LCS PROFILE SYNC + FAST AUTH FIX — 2026-08-28

Changes
- Firebase Authentication now initializes before Firestore so saved Google sessions resolve without waiting for the database module.
- Added preload/preconnect hints for Firebase App/Auth modules.
- Startup no longer waits on setPersistence(); persistence is still explicitly set to browserLocalPersistence before Google sign-in.
- Added a dedicated realtime listener for the signed-in user's public profile document.
- Public-profile saves are read back from the Firestore server and compared to the values submitted before the UI reports them as verified.
- Account UI now reports Synced / Editing / Connecting state and provides a View public profile button.
- Account form is dirty-state aware, so unrelated realtime profile updates can no longer overwrite unsaved edits.
- Generic public users subscription no longer overwrites the owner profile while editing.
- Save status is retained instead of being immediately erased by renderAccount().

No Firestore rules change is required for this patch.

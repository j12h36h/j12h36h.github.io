LCS AUTH STATE CONSISTENCY FIX — 2026-08-28

Fixed the contradictory Account screen that could show “Not signed in” at the same time as an authenticated Google identity.

Root cause
----------
The signed-out card used `.account-signed-out { display:grid; }`. That author CSS could override the browser's normal rendering for the HTML `hidden` attribute. The JavaScript state was authenticated correctly, but the stale signed-out card remained visible.

Changes
-------
- Added a global `[hidden] { display:none !important; }` invariant.
- Added explicit hidden-state selectors for all Account authentication panels.
- Added a “Checking sign-in” state while Firebase restores browserLocalPersistence.
- Prevented the header and Account page from briefly claiming the user is signed out before Firebase has resolved the saved session.
- Added an explicit private Account connection status showing that the LCS profile is linked to the current Google/Firebase sign-in.
- Kept the public profile keyed to the Firebase Authentication UID (`users/{uid}`); Google email/name remain outside the public profile document.
- Updated CSS/JS cache-busting tokens.

No Firestore rule change is required for this patch.

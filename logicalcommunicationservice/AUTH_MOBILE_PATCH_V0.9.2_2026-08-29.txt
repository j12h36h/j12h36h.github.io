LCS v0.9.2 — desktop-parity Firebase authentication

- Removed the Firebase Hosting auth bridge and all GIS/custom OAuth mobile paths.
- Mobile and desktop now call the exact same Firebase GoogleAuthProvider + signInWithPopup path.
- Kept Firebase browserLocalPersistence before authentication and auth-state recovery afterward.
- Expanded the page CSP to allow Firebase Auth's Google helper dependency at https://apis.google.com as well as the existing Firebase/Google endpoints.
- Added SecurityPolicyViolation diagnostics so a future auth/internal-error will identify a blocked Google/Firebase resource when CSP is the cause.
- /lcs-mobile/ stays on GitHub Pages for the entire application flow; no Firebase Hosting deployment is required.
- No Google Cloud Console / custom OAuth origin setup is required by this build.
- Firestore rules remain bundled and include the Founder legacy-channel repair/update exception.

LCS v0.2 — Account / Public Identity Privacy Patch
Date: 2026-08-28

Added:
- Dedicated Account view in the main LCS navigation.
- Editable public Display Name (2–40 characters).
- Optional public bio (up to 240 characters).
- Optional Google profile-picture sharing, OFF by default.
- Private signed-in Google account summary visible only to the signed-in browser session.
- Clear public/private visibility explanation.
- Top-right signed-in identity now opens Account and uses the LCS public identity.
- New accounts receive a privacy-safe generated Member-XXXXXX public name instead of automatically exposing the Google provider name.
- Composer and new posts/projects use the LCS public display name rather than the Google provider display name.
- Feed rendering resolves authors through the editable public profile, so profile changes update displayed names.
- Best-effort migration updates existing authored posts/objects after a profile change.
- Privacy Policy updated for the separated provider/public identity model.
- Firestore rules tightened so public user documents can contain only public display name, bio, photo opt-in/URL, and timestamps.

Important deployment note:
The website files can be pushed to GitHub Pages normally. For the stricter public-profile privacy boundary, also deploy the included firestore.rules to the logicalcommunicationservice Firebase project.

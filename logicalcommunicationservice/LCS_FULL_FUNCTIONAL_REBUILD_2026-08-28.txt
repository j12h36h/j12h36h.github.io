Logical Communication Service — Full Functional Rebuild
Date: 2026-08-28
Version: v0.3

PURPOSE
-------
This release replaces the prototype/demo behavior with a live Firebase-backed network while preserving the existing purple/orange LCS visual identity and the DAI Universe connection.

AUTHENTICATION
--------------
- Firebase Authentication is the single source of truth for signed-in state.
- Google sign-in uses browser-local Firebase persistence.
- Page refresh no longer relies on a second custom login-state marker.
- The account page and top-bar identity are rendered from the same auth observer.
- Public LCS display name remains independent from the private Google provider name/email.

LIVE FIRESTORE FEATURES
-----------------------
- Public realtime posts
- Public realtime profiles
- Public spaces
- Ideas / problems / projects
- Helpful reactions
- Follows for work and profiles
- Discussion comments
- Post-to-work links
- Work-to-work relationships
- Search across posts, people, spaces, and work
- Realtime map connections
- Computed trending tags and relationship types

REMOVED PROTOTYPE BEHAVIOR
--------------------------
- No seed/sample posts
- No seed/sample projects
- No fake "Helpful" toggle
- No staged "Connect" toast
- No fixed fake trending counts
- No local guest/demo identity
- No automatic fallback to example content when Firestore is empty or unavailable

DEPLOYMENT REQUIREMENT
----------------------
Deploy logicalcommunicationservice/firestore.rules after publishing the website. The new interactive collections are denied by the previous v0.2 catch-all rule until the v0.3 rules are deployed.

Firebase CLI example:

  firebase login
  firebase use logicalcommunicationservice
  firebase deploy --only firestore:rules

The Firebase Web App config remains browser client configuration. Do not add service-account JSON, OAuth client secrets, or private keys to the repository.
